# نسخة احتياطية لبيانات السيتات

`dambala_all_150_sets.csv` — كل الـ150 سيت (900 كرت، 2700 سطر) بصيغة الاستيراد.

## الأعمدة
`set_no, card_no, row_no, c1 … c9`

- `set_no` — رقم السيت (1–150)
- `card_no` — رقم الكرت داخل السيت (1–6)
- `row_no` — رقم السطر داخل الكرت (1–3)
- `c1 … c9` — خانات السطر. الخانة الفارغة تعني لا يوجد رقم.

## قواعد الأعمدة
c1 = 1–9 · c2 = 10–19 · c3 = 20–29 · c4 = 30–39 · c5 = 40–49
c6 = 50–59 · c7 = 60–69 · c8 = 70–79 · c9 = 80–90

## قواعد الصحة
- كل سطر يحتوي 5 أرقام و4 فراغات
- كل كرت يحتوي 15 رقم
- كل سيت يحتوي الأرقام 1–90 كاملة بدون تكرار ولا نقص

## الاستعادة
ارفع الملف من صفحة `/admin/import`.
تنبيه: `POST /api/sets` يمسح كل السيتات الموجودة قبل الاستيراد.
